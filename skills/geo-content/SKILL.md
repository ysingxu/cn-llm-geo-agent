# GEO内容质量与E-E-A-T评估（中国LLM版）

## 目的

AI搜索平台不只是找到内容——它们评估内容是否值得被引用。评估的主要框架是**E-E-A-T**（经验、专业知识、权威性、可信度），该框架现适用于**所有竞争性查询**。在中国市场，这些信号的表现形式与全球有所不同：专业知识通过中文原创内容体现，权威性通过知乎高赞回答和百度百科词条体现，可信度通过ICP备案和企业认证体现。

---

## E-E-A-T框架（总计100分）

### 经验（Experience）— 25分

直接第一手知识和与话题的实际接触。AI平台越来越能区分**报道**某话题的内容和**亲身经历**的内容。

**评估信号：**

| 信号 | 分值 | 评分方式 |
|---|---|---|
| 第一人称叙述（"我们测试了..."、"我们实施了..."） | 5 | 具体明确5分，泛泛而谈3分，无则0分 |
| 他处找不到的原创研究或数据 | 5 | 原创数据5分，引用原创工作3分，无则0分 |
| 含具体结果的案例研究 | 4 | 详细含数字4分，笼统2分，无则0分 |
| 直接使用的截图、照片或证据 | 3 | 真实证据3分，库存/通用图片1分，无则0分 |
| 来自个人经历的具体示例 | 4 | 具体独特4分，较具体2分，泛泛0分 |
| 流程演示（不只是结果） | 4 | 来自经验的分步介绍4分，部分2分，无则0分 |

**中国特定：** 基于中国本土实践的案例研究、国内平台（淘宝、微信、抖音等）的第一手使用经验，对中国AI系统有更高可信度。

---

### 专业知识（Expertise）— 25分

展示的知识深度和专业领域的胜任能力。

**评估信号：**

| 信号 | 分值 | 评分方式 |
|---|---|---|
| 作者资质可见（简介、学历、职称、资格证书） | 5 | 完整资质5分，基础简介3分，无作者0分 |
| 与话题相符的技术深度 | 5 | 深入技术处理5分，充分3分，浮浅0分 |
| 方法论解释（如何得出结论） | 4 | 清晰方法论4分，部分解释2分，无则0分 |
| 有数据支撑的主张（统计、研究引用） | 4 | 充分有来源4分，部分有数据2分，无支撑0分 |
| 正确使用行业专用术语 | 3 | 准确专业用语3分，基础1分，有错误0分 |
| 含详细职业背景的作者页面 | 4 | 专门的作者页面4分，简短简介2分，无则0分 |

**中国特定：** 国内权威认证（注册医师、注册会计师、高级工程师等）对文心一言等百度生态产品的权威性信号尤为重要。

---

### 权威性（Authoritativeness）— 25分

被他人认可为该话题的可信来源。

**评估信号：**

| 信号 | 分值 | 评分方式 |
|---|---|---|
| 来自权威来源的入站引用 | 5 | 被主要来源引用5分，有部分引用3分，无则0分 |
| 作者被媒体/行业引用 | 4 | 有媒体提及4分，有行业提及2分，无则0分 |
| 行业奖项或认可 | 3 | 相关奖项3分，周边1分，无则0分 |
| 演讲嘉宾资质 | 3 | 已列出3分，无则0分 |
| 在权威平台发表（知网、核心期刊、主流媒体） | 4 | 一级刊物4分，行业媒体2分，无则0分 |
| 综合话题覆盖（话题权威性） | 3 | 网站全面覆盖该话题3分，部分覆盖1分，孤立0分 |
| 品牌在百度百科或知乎被提及 | 3 | 百度百科3分，知乎高赞提及2分，无则0分 |

---

### 可信度（Trustworthiness）— 25分

表明内容及其发布者可靠且透明的信号。

**评估信号：**

| 信号 | 分值 | 评分方式 |
|---|---|---|
| 联系方式可见（地址、电话、邮件） | 4 | 完整联系方式4分，仅邮件2分，无则0分 |
| 隐私政策存在并已链接 | 2 | 存在2分，无则0分 |
| 服务条款存在 | 1 | 存在1分，无则0分 |
| 有效证书的HTTPS | 2 | 有效HTTPS 2分，无则0分 |
| ICP备案号（中国托管必须） | 3 | 有备案号3分，无则0分（境外托管N/A） |
| 企业认证/营业执照（微信/百度平台） | 3 | 有认证3分，无则0分 |
| 真实客户评价和推荐语 | 3 | 已验证评价3分，有推荐语1分，无则0分 |
| 声明准确（未发现错误信息） | 4 | 所有声明准确4分，大部分准确2分，发现错误0分 |
| 明确的联盟/赞助披露 | 3 | 正确披露3分，未披露或缺失0分 |

## 内容质量指标

### 字数基准
这些是**底线，不是目标**。更多字数不等于更好内容。基准是充分覆盖该话题的最低长度。

| 页面类型 | 最低字数 | 理想范围 | 备注 |
|---|---|---|---|
| 首页 | 500 | 500-1500 | 清晰的价值主张，不是大段文字 |
| 博客文章 | 1500 | 1500-3000 | 全面但聚焦 |
| 支柱内容/终极指南 | 2000 | 2500-5000 | 话题全面覆盖 |
| 产品页面 | 300 | 500-1500 | 描述、规格、使用场景 |
| 服务页面 | 500 | 800-2000 | 是什么、如何、为何、面向谁 |
| 关于页面 | 300 | 500-1000 | 公司/个人故事和资质 |
| FAQ页面 | 500 | 1000-2500 | 全面回答，不是一句话答复 |

## AI内容评估

### 低质量AI内容信号（标记这些）

| 信号 | 描述 |
|---|---|
| 泛泛的表述 | "在当今快速发展的世界中..."、"值得注意的是..."、"归根结底..." |
| 无原创洞察 | 内容只是改写广泛可获得的信息 |
| 缺乏第一手经验 | 无个人故事、案例研究或具体示例 |
| 完美但空洞的结构 | 格式良好的标题下是肤浅的内容 |
| 无具体示例 | 使用抽象解释而非具体案例 |
| 重复的结论 | 每个章节用不同措辞重复同一观点 |
| 过度模糊化 | "总体上"、"在大多数情况下"而不说明具体是哪些情况 |
| 缺少人声 | 无观点、偏好或专业判断表达 |

## 中国市场特定内容评估

### 语言质量
- **简体中文原创性**：内容应为简体中文原创，而非从其他语言翻译（翻译内容被AI系统识别并降权）
- **地道表达**：使用中国大陆通行表达，避免台湾、香港等地区用语
- **避免机翻痕迹**：检查是否有机器翻译常见的不自然表达

### 话题权威性评估（中国市场特定平台）
1. **知乎覆盖**：品牌或作者是否在知乎相关问题下有权威回答？
2. **B站内容**：话题是否有相关视频内容覆盖？
3. **百度指数相关性**：内容是否覆盖百度指数显示的高搜索量话题？
