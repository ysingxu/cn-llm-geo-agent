# 品牌提及扫描器技能（中国LLM版）

## 核心洞察

品牌提及与AI可见性的相关性约比传统反向链接高3倍。在中国市场，**未关联品牌提及**——无超链接的品牌名称引用——对AI引用的预测能力远强于域名评分或反向链接数量。

关键发现：**提及出现的平台至关重要。** 并非所有提及都等值。知乎或B站上的提及比低权威博客上的提及对AI引用的权重大得多，因为AI训练数据和检索系统会不成比例地索引高互动平台。

---

## 中国AI引用的平台重要性排名

### 1. 知乎提及 — 相关性最强

**为何知乎最重要：**
- 知乎是中国最大的知识问答平台，月活用户超1亿
- 中国AI训练数据集大量收录知乎回答，尤其是高赞内容
- 文心一言、元宝、通义千问在回答专业问题时经常直接引用知乎
- 知乎长文答案被AI模型视为"中文版Wikipedia"——高权威性来源
- 高赞知乎回答（500+赞）被AI模型视为社区验证的权威内容

**检查内容：**
- **品牌知乎账号：** 品牌是否有官方知乎账号？发布频率？回答质量？
- **第三方提及：** 其他知乎用户在品牌相关问题下是否提及该品牌？情感如何？
- **高赞回答：** 品牌代表的回答是否有500+赞同？
- **专栏文章：** 品牌是否在知乎发布了行业深度文章？
- **被引用次数：** 品牌内容是否被其他高赞回答引用？

**知乎评分标准（0-100）：**

| 得分 | 标准 |
|---|---|
| 90-100 | 官方认证账号，100+高质量回答，多个500+赞回答，在行业问题下频繁被推荐 |
| 70-89 | 活跃官方账号，20-99个回答，有高赞回答，行业社区认可 |
| 50-69 | 有账号但发布不规律，偶有高赞，品牌名在知乎可被搜到 |
| 30-49 | 基础账号，回答少，有零星第三方提及 |
| 10-29 | 几乎无知乎存在，仅偶尔被提及 |
| 0-9 | 完全无知乎存在 |

---

### 2. B站（Bilibili）提及 — 高相关性

**为何B站重要：**
- B站是中国最大的视频平台，月活用户超3亿，以年轻用户为主
- AI训练数据大量收录B站视频字幕、描述和弹幕评论
- DeepSeek和豆包在回答技术/科普问题时经常引用B站视频
- B站视频字幕特别有价值——AI模型在对话语境中处理自然语言提及
- UP主测评和对比视频在AI引用中具有高信号价值

**检查内容：**
- **官方B站账号：** 品牌是否有活跃的B站账号？粉丝数？视频数量？更新频率？
- **第三方视频提及：** 其他UP主是否提及品牌？在什么情境下（测评、教程、对比）？
- **视频描述：** 品牌名是否出现在相关行业视频描述中？
- **弹幕/评论：** 品牌是否在相关视频的弹幕和评论中被讨论？
- **B站搜索可见性：** 搜索"[品牌名]"时B站是否显示结果？

**B站评分标准（0-100）：**

| 得分 | 标准 |
|---|---|
| 90-100 | 活跃官方账号，粉丝10万+，品牌在20+第三方视频中被提及，B站搜索可见 |
| 70-89 | 活跃账号，粉丝1万+，在10-19个第三方视频中被提及，有一定B站搜索存在 |
| 50-69 | 有账号但内容少，在5-9个第三方视频中被提及 |
| 30-49 | 账号存在但不活跃，在1-4个视频中被提及 |
| 10-29 | 无账号或空账号，仅在1-2个视频中被提及 |
| 0-9 | 完全无B站存在 |

---

### 3. 百度百科存在 — 高相关性

**为何百度百科重要：**
- 百度百科是中国最大的百科全书，是AI训练数据的基础来源之一
- 所有主要中国AI模型都以百度百科作为实体识别的一级来源
- 有百度百科词条是显著性的强信号，对AI模型识别品牌为"值得了解的真实实体"有重要影响
- 互动百科（已被百度收购）和中文维基百科也有一定作用，但权重较低

**检查内容：**
- **百度百科词条：** 品牌是否有百度百科词条？是否标记删除或质量问题？
- **创始人词条：** 创始人/CEO是否有百度百科页面？（强权威信号）
- **被引用次数：** 品牌网站是否在任何百度百科文章中被引用为参考来源？
- **词条质量：** 若有词条，是存根、一般还是详细级别？
- **Wikidata等效：** 品牌是否在Wikidata有条目（有助于国际AI识别）？

**百度百科评分标准（0-100）：**

| 得分 | 标准 |
|---|---|
| 90-100 | 详细百度百科词条，被多篇文章引用为来源，创始人有词条 |
| 70-89 | 百度百科词条存在（一般级别或以上），品牌在2+其他词条中被提及 |
| 50-69 | 百度百科词条存在（存根或一般级别），有限的相互引用 |
| 30-49 | 无词条，但品牌在其他词条中被提及或被引用为来源 |
| 10-29 | 仅在1-2篇百度百科文章中被顺带提及 |
| 0-9 | 无任何百度百科存在 |

---

### 4. 微博存在 — 中等相关性

**为何微博重要：**
- 微博是中国最大的微博客平台，月活用户超5亿
- 微博内容被中国AI训练数据收录，尤其是高互动帖子
- AI模型引用微博用于了解实时话题、品牌情感和公众舆论
- 企业微博蓝V认证是品牌真实性的信号

**检查内容：**
- **官方微博账号：** 品牌是否有蓝V认证账号？粉丝数？发布频率？互动指标？
- **员工思想领袖：** 管理层是否发布提及品牌的行业内容？
- **品牌被提及：** 非员工的微博用户是否在帖子中提及品牌？
- **话题互动：** 品牌是否参与相关热门话题讨论？

---

### 5. 小红书 — 消费品高相关性

**为何小红书重要：**
- 小红书是中国最大的生活方式内容平台，对消费品、美妆、时尚品牌极为重要
- AI模型在回答消费者产品推荐时引用小红书内容
- 真实用户生成的测评内容被AI视为高可信度来源
- 通义千问（阿里巴巴有投资）和豆包对小红书内容加权

---

### 6. 其他补充平台

#### 微信公众号
- **重要性：** 对元宝（腾讯混元）极为重要
- **检查内容：** 是否有企业认证公众号？发布频率？文章阅读量和互动？

#### 抖音
- **重要性：** 对豆包（字节跳动）高度重要
- **检查内容：** 官方账号是否存在？视频数量？粉丝数？第三方提及？

#### 行业论坛/社区
- **重要性：** 适度，但对B2B品牌价值较高
- **检查内容：** 品牌是否在CSDN（技术）、36氪（商业科技）、虎嗅（商业）等垂直平台被讨论？

## 综合品牌权威得分

### 评分公式

| 平台 | 权重 | 依据 |
|---|---|---|
| 知乎存在 | 30% | 与AI引用相关性最强（中文知识权威） |
| B站存在 | 25% | 第二强相关；对科技和消费品尤为重要 |
| 百度百科/百科 | 20% | 实体识别基础；AI训练数据核心 |
| 微博权威 | 15% | 品牌实体信号；公众认知度 |
| 其他平台 | 10% | 小红书、微信、抖音、行业论坛的补充信号 |

**公式：**
```
品牌权威得分 = (知乎 * 0.30) + (B站 * 0.25) + (百度百科 * 0.20) + (微博 * 0.15) + (其他 * 0.10)
```

### 得分解读

| 分数范围 | 评级 | 解读 |
|---|---|---|
| 85-100 | 主导型 | 品牌在中国AI平台上是知名实体，极可能被AI系统引用和推荐 |
| 70-84 | 强势型 | 品牌有扎实的跨平台存在，AI系统很可能识别并引用 |
| 50-69 | 中等型 | 品牌在部分平台有存在，但存在差距，AI引用不稳定 |
| 30-49 | 弱势型 | 品牌平台存在有限，AI系统可能无法将其识别为独立实体 |
| 0-29 | 极弱型 | 品牌平台存在可忽略，AI系统极不可能引用或推荐 |

## 分析流程

### 第一步：收集品牌信息

从用户处或网站收集以下信息：
- **品牌名称**（精确拼写，含任何官方变体）
- **创始人/CEO姓名**
- **域名URL**
- **行业/类别**
- **主要产品或服务**（前3项）
- **主要竞争对手**（对比参考）

### 第二步：平台扫描

**知乎检查：**
1. 搜索：`[品牌名] site:zhihu.com`
2. 检查：`zhihu.com/org/[品牌名]` 是否有官方机构账号
3. 搜索：`"[品牌名]" site:zhihu.com`（精确匹配）
4. 记录：账号存在、回答数量、最高赞同数、情感

**B站检查：**
1. 搜索：`[品牌名] site:bilibili.com`
2. 检查：`space.bilibili.com` 是否有官方账号
3. 搜索视频描述中的品牌名提及
4. 记录：频道订阅数、视频数、最近上传日期、第三方提及数

**百度百科检查：**
1. WebFetch：`https://baike.baidu.com/item/[品牌名]`
2. 检查词条是否存在、质量等级、被引用情况
3. 检查互动百科和中文维基百科作为补充

**微博检查：**
1. 搜索：`[品牌名] site:weibo.com`
2. 检查：`weibo.com/[品牌名]` 是否有官方账号
3. 记录：粉丝数、发布频率、互动水平、是否蓝V认证

**其他平台：**
1. 搜索：`[品牌名] site:xiaohongshu.com`（小红书）
2. 搜索：`[品牌名] site:mp.weixin.qq.com`（微信公众号文章）
3. 搜索：`[品牌名] site:douyin.com`（抖音）
4. 搜索：`[品牌名] site:csdn.net`（技术品牌）
5. 搜索：`"[品牌名]"`——过滤至最近6个月——覆盖新闻提及

### 第三步：情感评估

对知乎和其他讨论平台，通过分析最近和最突出的提及来评估情感：

| 情感 | 指标 |
|---|---|
| **正面** | 推荐（"我很喜欢[品牌]"、"我们换用[品牌]后..."），高赞提及，正面对比 |
| **中性** | 事实提及（"我们用[品牌]做..."），关于品牌的问题，平衡比较 |
| **负面** | 投诉（"避开[品牌]"、"[品牌]售后很差"），低赞推荐，负面对比 |
| **混合** | 正负兼有。记录比例和主要主题。 |
