# llms.txt标准分析与生成技能（中国LLM版）

## 目的

本技能处理所有与 `llms.txt` 标准相关的事务——这是一个新兴惯例（由Jeremy Howard于2024年9月提出，2025-2026年间逐渐被采用），允许网站向AI系统提供有关其内容、结构和关键信息的结构化指引。对于面向中国市场的网站，llms.txt中应包含**简体中文描述**，并特别标注对国内AI平台（豆包、文心一言等）重要的内容。

截至2026年初，不足5%的网站拥有llms.txt文件——先行者优势明显。对于中国市场，这一比例更低，是显著的差异化机会。

---

## llms.txt规范

### 文件位置
文件**必须**位于域名根目录：
```
https://example.com/llms.txt
```

### 格式规范

```markdown
# [网站名称]

> [一句话描述网站/业务的内容。保持在200字符以内。简体中文。]

## 文档

- [页面标题](https://example.com/page-url): 此页面内容的简洁描述及其重要性。
- [另一页面](https://example.com/another-page): 内容描述。

## 可选

- [次要页面](https://example.com/optional-page): 描述。
```

### 中国市场llms.txt扩展建议

在标准格式基础上，建议添加以下中国特定章节：

```markdown
## 关键平台账号

- 微信公众号: [公众号名称] — 关注获取[类型]内容
- 知乎: [知乎账号URL] — 行业问答和深度分析
- 微博: [微博账号URL] — 最新动态和公告
- B站: [B站频道URL] — 视频教程和产品演示
- 抖音: [抖音主页URL] — 短视频内容
```

## 分析模式

### 第一步：获取文件

1. 使用WebFetch获取 `[domain]/llms.txt`
2. 同时检查 `[domain]/llms-full.txt`
3. 记录HTTP状态码

### 第二步：验证格式

| 元素 | 检查 | 缺失严重性 |
|---|---|---|
| H1标题 | 存在，与业务名称匹配 | 严重 |
| 引用块描述 | 存在，200字符以内，事实性，**简体中文** | 高 |
| 至少一个H2章节 | 存在 | 严重 |
| 含URL的页面条目 | 至少5个条目存在 | 高 |
| URL使用绝对路径 | 所有URL使用完整https://路径 | 高 |
| URL有效 | 所有URL返回200状态 | 中 |
| 描述存在 | 每个条目冒号后有描述 | 中 |
| 关键事实章节 | 存在并含业务信息 | 中 |
| 中国平台账号（新增） | 如有中国平台存在则包含 | 中 |
| 联系方式 | 至少有联系邮件 | 低 |

### 第三步：评估内容质量

**对中国市场的额外评估：**
- 描述是否使用简体中文（而非英文）？
- 关键事实是否引用中国相关数据（如中国用户数量、中国市场覆盖）？
- 是否包含中国平台账号信息？
- 页面条目是否覆盖了面向中国用户的重要页面？

## 生成模式

### 中国网站llms.txt生成模板

```markdown
# [网站名称]

> [简体中文的一句话描述：业务内容、服务对象和主要价值主张。200字符以内。]

## 文档

- [最重要页面](https://example.com/page): 描述此页面的关键内容及对用户的价值。
- [第二重要页面](https://example.com/page-2): 此页面内容的描述和价值。
- [第三页面](https://example.com/page-3): 用户和AI系统将在此找到的内容。

## 产品/服务

- [产品A](https://example.com/product-a): 产品A的核心功能、目标用户和定价模式。
- [产品B](https://example.com/product-b): 产品B的功能及与产品A的区别。

## 资源

- [指南标题](https://example.com/guide): 全面指南，涵盖[话题]，包含[X]个章节和实际示例。
- [博客文章](https://example.com/blog/post): 基于[来源]原创数据对[话题]的分析。

## 关键信息

- 成立于[年份]，创始人：[姓名]
- 总部：[城市，省份，中国]
- [具体指标：如"服务中国10000+家企业"]
- [差异化优势：如"唯一提供X和Y实时集成的平台"]
- 行业：[分类]

## 中国平台

- 微信公众号：[公众号名称] — 行业洞察和产品更新
- 知乎：[知乎URL] — 专业问答和深度内容
- 微博：[微博URL] — 最新动态

## 联系方式

- 网站：https://example.com
- 邮件：[主要联系邮件]
- 客服：[客服URL或邮件]
- 微信客服：[微信号]（如有）
```

## 输出格式

### 分析模式
生成 `GEO-LLMSTXT-ANALYSIS.md`（含验证详情和改进建议）

### 生成模式
输出完整的 `llms.txt` 文件内容，可直接保存到网站根目录，同时输出简短报告 `GEO-LLMSTXT-GENERATION.md` 说明：
- 发现了多少页面，选择了多少
- 优先级考虑依据
- 可选择性添加的边缘案例页面
- 建议更新频率（活跃博客每月，稳定网站每季度）
- 中国平台账号的发现情况
