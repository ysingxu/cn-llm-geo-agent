# GEO月度对比报告生成器（中国LLM版）

## 目的

GEO机构最强大的留存工具：向客户展示**自合作以来的精确改进情况**。GEO得分每提升一分都是价值证明。本技能生成"看看您的进展"报告。

---

## 命令

```
/geo compare <域名>
/geo compare <基准文件> <当前文件>
/geo compare example.com --month march-2026
```
