# GEO提案生成器（中国市场版）

## 命令

```
/geo proposal <域名或审计文件> [--tier basic|standard|premium] [--client-name "名称"] [--monthly CNY]
```

**示例：**
```
/geo proposal example.com
/geo proposal example.com --tier standard --client-name "示例科技有限公司"
```

---

## 工作流

### 第一步：加载审计数据
1. 检查 `~/.geo-prospects/audits/<domain>*.md` 是否存在
2. 若不存在，建议先运行 `/geo quick <domain>`
3. 从审计中提取：
   - GEO得分（总分和各类别）
   - 前3个严重发现
   - 快速胜利列表
   - 业务类型

### 第二步：自定义提案

根据得分推荐服务层级：
- 得分0-40 → 推荐高级套餐
- 得分41-60 → 推荐标准套餐
- 得分61-75 → 推荐基础套餐
- 得分76+ → 基础套餐或季度检查
