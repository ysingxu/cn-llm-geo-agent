### 词汇表

| 术语 | 定义 |
|---|---|
| GEO | 生成式引擎优化——优化内容以被AI搜索平台引用 |
| E-E-A-T | 经验、专业知识、权威性、可信度——内容质量评估框架 |
| SSR | 服务端渲染——在服务器上生成HTML，爬虫无需JavaScript即可读取内容 |
| ICP备案 | 互联网内容提供者备案——在中国大陆运营网站的法律要求 |
| llms.txt | 向AI系统提供网站内容指引的提议标准文件 |
| 知识图谱 | 搜索引擎和AI系统用来理解实体及其关系的结构化实体数据库 |
| CWV | 核心Web指标——Google的页面体验指标（LCP、INP、CLS） |
| LCP | 最大内容绘制——渲染最大可见元素的时间 |
| INP | 下次交互绘制——响应性指标（2024年3月替代FID） |
| CLS | 累积布局偏移——视觉稳定性指标 |
